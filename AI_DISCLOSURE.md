# AI Use Disclosure

## Purpose

AI tools were used as supplementary assistance during the development of this educational C project. They supported learning, debugging, review, and documentation; they were not treated as an authority or a substitute for understanding the code.

## Areas of assistance

AI assistance was used to:
- Explain C language concepts and help reason about possible bugs.
- Review selected code and suggest potential fixes or improvements.
- Discuss input validation, error handling, and test cases.
- Improve the clarity and organization of project documentation.

The exact contribution varied by task. This disclosure does not imply that every line of code was generated by AI.

## Developer responsibility

The project developer is responsible for the final source code, design choices, testing, and maintenance. Suggestions were reviewed and adapted where appropriate; generated output was not accepted blindly.

## Limitations and safe use

This application is a learning project, not production banking software. It has known security and reliability limitations, including plaintext PIN storage and local, unencrypted data files. Do not use real credentials, personal information, or real money with this program.

AI-generated suggestions can be incomplete, incorrect, or insecure. They must be checked and tested before use. The security limitations documented in [SECURITY.md](SECURITY.md) continue to apply regardless of whether AI assistance was used.

## Transparency

This disclosure is intended to make the role of AI assistance clear to readers and contributors.

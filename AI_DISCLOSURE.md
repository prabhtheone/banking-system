# AI Usage Disclosure

## Overview

This project was developed as a learning project to improve my understanding of C programming, software development, and basic banking system operations.

AI tools were used as supplementary development and learning assistants during the development of this project.

## How AI Was Used

AI assistance was used for:

- Understanding C programming concepts and debugging errors.
- Reviewing code for potential bugs and suggesting improvements.
- Improving code readability, structure, and documentation.
- Suggesting input validation and error-handling improvements.
- Helping write and refine project documentation, including the README.
- Explaining programming concepts and suggesting possible enhancements.

## Human Responsibility

The project owner is responsible for the final code, project decisions, and submitted changes.

AI-generated suggestions were reviewed and adapted where appropriate. AI output was not treated as automatically correct, and implementation decisions remained under human control.

## Limitations

- AI-assisted code may contain mistakes or security vulnerabilities.
- This project is intended for educational purposes and is not a production-ready banking application.
- It does not implement the security, encryption, regulatory compliance, or infrastructure required by real banking systems.
- Users should not store real banking credentials, personal information, or financial data in this application.

## Transparency

I believe AI can be a useful development and learning tool when used responsibly. This disclosure is intended to provide transparency about where AI assistance contributed to the development process.
